# 🛰️ StarDesk — StarLink Service Desk

**StarDesk** — це веб-система для управління заявками, KIT-кодами та UTID-ідентифікаторами в екосистемі StarLink. Вона створена для зручного обліку активних, буферних та деактивованих ліцензій, з можливістю зміни статусів, перетягування (drag-and-drop) і повного логування дій.

Проект повністю адаптований для роботи на **мобільних пристроях**, зокрема на смартфонах **Redmi** (та інших на Android), завдяки гнучкому адаптивному дизайну.

---

## 🚀 Основні можливості

- 🔐 **Вхід за роллю** (Адмін / Користувач) з PIN-кодом (адмін: `1234`, користувач: `5678`)
- 📋 **Управління заявками** (створення, редагування, видалення, зміна статусу)
- 🔑 **Робота з KIT-кодами** (активація, деактивація, переміщення між заявками)
- 📦 **Системні групи**: «Буфер» (вільні KIT) та «Деактивовані» (архів)
- 🖱️ **Перетягування KIT** (drag-and-drop) між заявками та групами (тільки для адміна)
- 📅 **Дата створення** кожної заявки (автоматично)
- 📊 **Фільтрація** заявок за типом дії (активувати, деактивувати, втрачено, інше)
- 📝 **Журнал подій** (всі дії логуються в реальному часі)
- 👥 **Розподіл прав**:
  - **Адмін** – повний контроль
  - **Користувач** – тільки перегляд своїх заявок та створення нових (без змін чужих)
- 📱 **Повна адаптація під смартфони** (Redmi, Xiaomi, Samsung тощо)

---

## 🛠️ Технології

- **HTML5 / CSS3** – адаптивна верстка
- **JavaScript (ES6)** – вся логіка
- **Firebase Realtime Database** – зберігання даних (заявки, логи)
- **Font Awesome** – іконки
- **Drag & Drop API** – перетягування (з підтримкою тач-екранів)

---

## 📦 Встановлення та налаштування

1. **Завантажте файл** `index.html` (або скопіюйте весь код).
2. **Створіть проект Firebase**:
   - Перейдіть до [Firebase Console](https://console.firebase.google.com/)
   - Створіть новий проєкт
   - Увімкніть **Realtime Database** у тестовому режимі (або з правилами доступу)
   - Скопіюйте конфігурацію проєкту (об'єкт `firebaseConfig`)
3. **Вставте конфігурацію** у відповідне місце в коді (рядки з `firebaseConfig`).
4. **Відкрийте `index.html`** у будь-якому сучасному браузері (Chrome, Firefox, Safari, або вбудований браузер на Redmi).

## 📱 Використання на Redmi

- Усі кнопки та елементи управління мають достатній розмір для зручного натискання пальцем.
- Перетягування KIT підтримує **тач-жести** (натисніть і тримайте, переміщуйте).
- Таблиця автоматично масштабується під ширину екрана, а колонки адаптуються.
- Журнал подій прокручується вертикально, щоб помістити багато записів.

## 📂 Структура даних Firebase

- `groups/` – заявки та системні групи:
  - `name` – назва
  - `kit` – основний KIT-код
  - `utid` – додатковий ідентифікатор
  - `status` – статус (active, inactive, whitelist, new, buffer, deactivated)
  - `completed` – виконано (true/false)
  - `createdBy` – хто створив (admin/user/system)
  - `isNew` – позначка нової заявки
  - `createdAt` – час створення (мілісекунди)
  - `buffer` – додаткові KIT (для системних груп)
- `logs/` – журнал подій:
  - `time` – час події
  - `msg` – текст події

## 🧩 Як це працює (коротко)

1. **Користувач** створює заявку через форму «Запит» (вказує KIT/UTID та текст дії).
2. Система автоматично визначає **фільтр** (активувати, деактивувати, втрачено, інше) за ключовими словами.
3. **Адмін** бачить всі заявки, може змінювати статуси, переміщувати KIT між заявками, а також перекидати їх у «Буфер» або «Деактивовані».
4. **Буфер** використовується для зберігання вільних KIT. Адмін може перетягнути KIT з буфера на заявку (при цьому старий KIT, якщо був, автоматично повертається в буфер).
5. **Деактивовані** – група для KIT, які більше не використовуються (наприклад, втрачені або списані).
6. Усі дії **логуються** в реальному часі.

## 📌 Примітки для розробників

- Код написаний у одному HTML-файлі, що спрощує розгортання.
- Для роботи з Firebase використовується SDK `compat` (не модульний), тому не потрібні збірники.
- Якщо потрібно змінити паролі – відредагуйте об'єкт `PASSWORDS` у скрипті.
